# Curvature-aware geometry and experiment code

Start with the [repository README](../README.md) for the current paper's reproduction commands and result mapping.

`experiments/` contains four current FVM/calibration/transport scripts. `src/` contains the geometry/transport implementation and additional JAX neural architecture prototypes. `run_experiment.py` is a prototype rather than the source of the current paper tables. Dependencies for that prototype are optional and have not been verified during packaging.

Earlier synthetic experiment scripts and results are separated under `../archive/legacy/`. The README from the source workspace is retained as `../docs/ORIGINAL_PROJECT_README.md` for provenance.
