# Second-revision experiment code

The restored and rerun experiment suite is generated by:

- `curvature_aware_deeponet/experiments/run_proof_of_concept.py`
- `curvature_aware_deeponet/experiments/run_remaining_v2.py`
- `curvature_aware_deeponet/experiments/run_comparison.py`
- `curvature_aware_deeponet/experiments/run_exp5_exp6.py`
- `run_largescale_scalability.py`
- `run_epsilon_ablation.py`
- `run_inverse_poc.py`
- `run_transport_mesh_validation.py`
- `curvature_aware_deeponet/src/parallel_transport.py`

Run each script from the repository root. The original JAX-only Gaussian-process sampler now has a NumPy-compatible implementation with the same seeded RBF construction, allowing the FVM experiments to run in the present environment.

```text
python run_transport_mesh_validation.py
```

`run_transport_mesh_validation.py` independently validates tangent-vector transport on sphere, torus, elliptic-paraboloid, and wrinkle meshes and measures the transport-kernel cost on torus meshes up to 12,800 edges.

The restored scripts that inject and calibrate a scalar factor `1 + K L^2 / 6` are reported only as controlled implementation tests. They are not identified with Levi-Civita transport. The inverse table is generated by `run_inverse_poc.py`, which performs FVM grid search and local refinement; the improvement-factor calculation in `run_exp5_exp6.py` is not used for that table.
