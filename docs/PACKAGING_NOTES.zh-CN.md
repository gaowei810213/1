# GitHub 上传文件整理说明

整理日期：2026-10-11。依据当前论文 `manifold_drift_diffusion_algorithm.tex` 和原有 `REVISION2_CODE_NOTES.md`，以第二次修订实验为主。

## 整理方式

所有实验 Python 文件及选入的数据均直接复制，未改动算法、随机种子、参数或结果数值；原工作文件夹保持不变。`manifest.csv` 逐项记录原路径、上传路径、类别、字节数、原修改时间及 SHA-256，可核对复制完整性。

保留两个项目文件夹的相对位置，是因为实验程序依赖参考项目中的图定义、FVM 求解器及 GP 采样器；改变目录名称会影响导入。

上传目录中包括：

- 当前论文的 8 个实验入口及 8 个对应 JSON 结果。
- 几何、输运、图结构和模型源码；JAX 模型原型及原有基础检查脚本标明为可选。
- 必需参考项目源码、原 README 和 MIT 许可证，以及第三方来源说明。
- 早期实验代码、结果和日志，放入 `archive/legacy/`，与当前实验区分。
- 英文 README、依赖清单、实验数据说明、机器可读实验索引和验证记录。

## 已发现的版本与命名问题

原目录并未保存两套完整的历史 Python 源码快照。`修改前版本/` 只有论文文件。因此这里只能保留实际存在的源码和早期结果，不能宣称恢复了两次修改前后的完整代码版本。

`exp5_exp6.json` 中只有 `experiment5` 对应当前论文实验 5；其中 `experiment6` 是旧的代数改善因子模拟。当前论文实验 6 来自 `comparison.json/partA`，实验 8 来自 `inverse_poc.json`。`remaining_v2.json/experiment5` 也不是最新论文拓扑表的数据来源。

早期 `poc_results.pkl` 与当前同名 JSON 的日期和来源不同，已归档，不能作为当前 JSON 的二进制副本。旧日志也不对应所有最新重跑值。

部分原始代码注释仍使用旧名称或几何解释。上传包保留源码原样，并在 `docs/EXPERIMENTS.md` 说明：标量偏差校准实验不等同于 Levi–Civita 切向量输运，模型原型不等同于已完成训练的神经网络实验。

## 上传和使用

将 `github_upload` **里面的全部内容**作为 GitHub 仓库根目录上传，包含 `.gitignore`；不用再上传整个原工作目录。当前尚未向 GitHub 发布。

先阅读根目录 `README.md`。所有论文实验命令从仓库根目录运行；运行会覆盖相应 JSON，建议在另一份副本中复现。`requirements.txt` 是整理时验证环境的依赖版本，并非原始实验环境锁文件；可选 JAX 依赖和模型原型未在本次验证。

`docs/VALIDATION.md` 记录实际完成的校验与复现范围。数据主要为汇总结果，原目录没有每个实验的完整原始逐样本数据集；本次没有补造此类数据。
